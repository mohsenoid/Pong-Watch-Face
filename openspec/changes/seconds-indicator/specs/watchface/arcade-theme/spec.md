## ADDED Requirements

### Requirement: Seconds indicator
The watch face SHALL display the current seconds value somewhere in active mode, updating at least once per second, positioned so it does not compete visually with the primary `hh:mm` time display.

#### Scenario: Seconds value updates every second
- **WHEN** the device's seconds value changes while the watch face is in active mode
- **THEN** the displayed seconds indicator updates to match
