## Why

The current decorative scene (a river strip with a drifting jet sprite) works, but it's a generic river-shooter idea rather than something that reads as a specific, distinctive retro-game moment. The user found "Refraction" — an original 2018 Atari 2600 homebrew game by Norbert Landsteiner (RetroChallenge 2018, not a commercial/licensed title) — whose core visual is a missile that bounces and bends ("refracts") across a central barrier between two ships. That's a more distinctive, game-like visual to build the watch face's decorative element around than a static river scene, and it's genre-inspired from an independent homebrew project rather than a copy of commercial IP (a lower-weight version of the copyright consideration already applied to the original River Raid discussion).

## What Changes

- Remove the river-strip + jet-sprite decorative `Group` and its two drawables (`river_strip.png`, `sprite_jet.png`).
- Add a new "Refraction Arena" `Group` in the same screen position (the band below the time display): a bright vertical divider at horizontal center, two small original geometric ship sprites near the left/right edges (not traced from Refraction's actual sprites — simple wedge/triangle shapes in the spirit of early Atari 2600 geometric sprites), and one small bouncing element that moves back and forth across the full band width, crossing the divider each pass, driven by `[SECOND]` via a `<Transform target="x" value="...">` child element (the pattern already proven correct in the prior change, so no repeat of that debugging cycle).
- New pixel-art assets generated by the existing `generate_pixel_assets.py` script: divider bar, two ship sprites, one bouncing "missile" glyph — replacing the river/jet assets.
- Update the `watchface/arcade-theme` spec: replace the "Drifting original sprite" requirement with a new one describing the arena scene, and adjust the wording of the "Scanline background" and "Ambient mode simplification" requirements' scenarios where they currently reference the "sprite/river group" (renaming to "arena group").
- No changes to the digit font, hour-tens digit logic, colon, scanline background, branding, or ambient time text — all of that stays exactly as shipped in the previous change.
